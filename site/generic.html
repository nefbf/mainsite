Core Tools

Overview of the core tools and technologies used in the examples: Ansible, Terraform, Docker, Kubernetes, Bash/PowerShell, Linux, and AWS.

This site contains short, practical examples and explanations for commonly used DevOps tools. Explore playbooks, IaC modules, Dockerfiles, Kubernetes manifests, and automation scripts in the Examples section.

  • Go to Examples
  • Documentation

Highlighted Tools

  • Ansible — configuration management and orchestration with roles & playbooks.
  • Terraform — Infrastructure as Code for cloud provisioning and stateful resources.
  • Docker — containerize applications for consistent builds and environments.
  • Kubernetes — orchestrate containers at scale with deployments and services.
  • Bash & PowerShell — scripting for automation across Linux and Windows.
  • AWS — cloud provider used in infrastructure examples.
